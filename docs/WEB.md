# Дашборд: состояние пула в браузере

`mop web` отдаёт по HTTP ту же картину, что `mop list`, `mop node` и
`mop stat`, одной страницей на русском, которая обновляется на месте.
Адрес — `https://<MOP_SERVER_LAN>/` (порт — `MOP_HTTPS_PORT`, по умолчанию
443): снаружи дашборд виден только через TLS-прокси nginx на сервере
(`deploy/roles/proxy`, #96). Сам `mop web` слушает `MOP_WEB_BIND:MOP_WEB_PORT`,
по умолчанию `127.0.0.1:9000`: открытый HTTP рядом с прокси был бы второй
дорогой мимо TLS.

Сертификат — `MOP_TLS_CERT` и `MOP_TLS_KEY` в `.env`, пути на контроллере.
Не заданы — `mop deploy` один раз заводит самоподписанный в `secrets/` на имя
`MOP_SERVER_LAN`, и браузер о нём предупредит. Продление — заменить файлы и
прогнать deploy: nginx перечитывает сертификат по reload.

Только чтение, и это решение: у страницы нет входа, а рестарт папета с кнопки
убивает работу в его клоне и `AGENT SILENT` не лечит. Действия остаются в
`mop` и в руках оператора.

## Устройство

| Слой | Где | Что делает |
|---|---|---|
| снимок | `mop/web.py` | чистые функции: корзина папета, группы по проектам, счётчики, ось расхода |
| сборщик | `mop/web.py`, `Collector` | три потока с тремя расписаниями держат снимок и версию |
| HTTP | `mop/cli/service/web.py` | stdlib `http.server`: `/`, `/api/pool`, `/events` (SSE), `/healthz` |
| страница | `web/index.html` | ванильный JS без сборки: читает снимок и красит |
| события | `mop/agent.py`, `_event` | агент пишет в `mop.<проект>.events`, дашборд подписан под `service` (#104) |
| раскатка | `deploy/roles/web` | пакет, зависимости, креды мастера и юнит `mop-web` на сервере |

Фреймворка нет намеренно. Список pip-зависимостей один на систему
(`mop/deps.py`) и едет в каждое тело папета; веб-фреймворк ради страницы
статуса приехал бы и туда. Сборки фронта нет по той же причине: в `deploy/`
нет node-тулчейна, и npm ради одной страницы был бы именно им.

## Три расписания

Три опроса стоят по-разному, и один общий круг показывал бы состояние с
опозданием на самый медленный:

| Что | Период | Цена |
|---|---|---|
| ростер Nomad + состояния с узлов | 15 с | десятые доли секунды |
| обмер места (`sizes`, du по target) | 2 мин | секунды IO на узле, под nice |
| расход токенов (`usage`, разбор транскриптов) | 10 мин | до полутора минут по всем телам |

Диагностики `mop doctor` на странице нет (решение оператора 2026-09-22): она
стоила запроса к Nomad на каждого папета каждым кругом, а лечение всё равно
остаётся за `mop doctor`; больной папет виден корзиной `sick`.

Событие на шине сдвигает быстрый круг вперёд с паузой в секунду на пачку:
после `send` папет читается занятым через секунду, а не через четверть
минуты. Смену состояния внутри сессии агент не видит, поэтому опрос остаётся
основой, а события — ускорителем и журналом.

## Корзины

Страница не разбирает текст состояния второй раз: корзину считает
`web.classify`, по тем же префиксам, по которым `doctor` назначает лечение.

| Корзина | Когда |
|---|---|
| `down` | аллокация не работает (pending, lost, queued, ошибка ростера) — спрашивать некого |
| `silent` | `AGENT SILENT`: молчит узел, не папет; лечения с мастера нет |
| `free` | `puppets.is_free`: в клоне нет несохранённой работы |
| `sick` | `HUNG`, `needs action`, `not logged in`, `login expired`, `no model quota`, `error` |
| `busy` | всё остальное, включая `waiting for input` |

Матрица проверяется без пула: `python3 tests/web.py`.

## Кто и где

Дашборд читает пул как мастер: по токену Nomad и под `service` шины. Ни того ни
другого узлам не дают, поэтому он живёт на сервере, рядом с NATS, а не на
узле; и не на машине оператора — страница нужна, когда мастер-шелл закрыт.
Роль кладёт креды в тот же каталог, откуда их читает любой мастер
(`~/.config/mop/servers/<адрес>/`, `mop/creds.py`), и второго способа
представиться шине у дашборда нет. `.env` на сервер не едет: адрес сервера и
порты юнит передаёт окружением.

Порт наружу не проброшен и проброшен быть не должен — та же логика, что у
шины на 4222 и у API Nomad на 4646: границу держит роутер. На странице видны
имена узлов, origin'ы проектов и состояния — ровно то, что показывает UI
Nomad на 4646.

## Проверка

`mop deploy` в конце роли ждёт `200` от `/healthz` — это «первый снимок
собран», а не «процесс запущен»: юнит в бесконечном рестарте systemd вполне
устраивает. Роль proxy затем запрашивает тот же `/healthz` с контроллера
сквозь TLS. Руками: `curl https://<сервер>/api/pool` (с самоподписанным —
`--cacert ~/.config/mop/secrets/tls.pem`).
